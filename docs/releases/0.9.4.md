# dsh-breaklimit 0.9.4 内测版

这一版把设置页和浮窗整体换成新界面，新增目标词库管理和检查更新。0.9 系列用于内测，正式版计划为 1.0.0。

## 新界面：设置页与浮窗

设置页改为五个页签：概览、补丁、提示词、规则、词库。每页顶部写明这一页管什么、改动什么时候生效，概览页首是主行动卡。第一次打开有三步引导，按顺序准备宿主目录、应用补丁、编辑提示词；第三步会连「还有文件待写入」一起判断是否完成，可以随时收起。右上角的帮助按钮给出各功能的生效时机。深色模式跟随宿主主题，系统是深色时也正确。

聊天区的「破限」浮窗改成真正的窗口：可以拖动、缩放，位置和大小刷新后还在。浮窗里能直接切换提示词模式、看当前词库前 3 条，点「管理词库」直达设置页的词库页签。

## 目标词库：统一管理替换词

词库在请求交给模型之前把真实目标名换成占位名，只作用于用户消息。新的词库页逐条新增、修改、删除，右侧实时预览替换效果（预览与真实替换逐例一致，仅用于查看）。保存时会去掉首尾空白；同一条原词再次保存即覆盖，上限 100 条、每条不超过 64 字符。覆盖、删除和放弃未保存的草稿都有二次确认。

词库读取失败时不会当成空词库：保留已有内容、暂停保存与预览并提示重试，避免误操作清掉词表。修改词库需要新开会话才生效。

## 检查更新

点设置面板顶栏的版本徽章打开「版本与更新」：手动检查更新、忽略某个版本、开关「每天自动检查一次」（默认开启）。打开设置面板或浮窗时至多每天静默查一次本插件的 GitHub 发布列表，有新版时顶栏直接显示「有新版本 x.y.z」。

检查只读取发布信息比较版本号，不发送本地配置、会话内容或词库规则；关闭自动检查后手动检查仍然可用。网络需要代理时读取 `HTTPS_PROXY` 等环境变量或 git 的代理设置，只支持 `http://` 代理；`https://` 代理会被拒绝并提示。

## 修复

- 弹窗里的 Esc 不再连带关闭设置面板；弹窗关闭后焦点回到打开它的按钮。
- 词库保存期间显示「保存中」，与读取失败分开提示，不再同屏混淆。
- 深色主题判定修复；开关与勾选框的形状、取色与宿主一致。
- 弹窗标题的元素 id 按实例隔离，两个浮窗同时打开不再冲突。
- 补丁预检被阻断时可以直接看到阻断原因，并能一键打开宿主目录配置说明。

## 安装与升级

适用于已能运行的 DeepSeek Harness **源码版 0.2.1-rc.2**，固定宿主提交为 `687f282e8625c6b8d11ff58211a90524be2e4317`。需要 Git、pnpm 和兼容的 Node.js，推荐 Node 24。

**第一次安装？** 下载附件 `dsh-breaklimit-0.9.4.zip`，解压到固定目录，再按 [README 安装指南](https://github.com/rumoii/dsh-breaklimit/blob/v0.9.4/README.md#快速安装windows-powershell) 准备 Web profile、安装插件、运行检查并应用补丁。

已经在用 0.9.3 的用户，保存本地修改后更新插件目录，再重启宿主即可。保留原有的 `DSH_HOME`、规则、词库与恢复快照；这个版本没有改变补丁内容与规则存储格式。更早版本的升级差异，以及回退和卸载步骤，见 [安装说明](https://github.com/rumoii/dsh-breaklimit/blob/v0.9.4/docs/install.md)。

## 使用范围

仅用于受信任的本机 Web 环境。插件管理接口尚未接入宿主登录认证，请勿将端口暴露给不受信任的网络。操作规则时，也请避免其他程序同时改写规则文件。

桌面版、其他宿主版本、Ubuntu 实际安装、完整模型与沙箱场景尚未验收。
