# 核心修复与验收

基线：`97c6716563186ab36435713f2c89b818a43e3a69`，0.9.5。范围为配置读取、内容保护、事务恢复及对应界面反馈。

## 约束与决定

- 正常提示词最终字节、两档预算值、补丁声明及词表替换语义保持不变。范围限于效果可靠性、内容保护、事务恢复和对应反馈。
- 配置读取失败沿用同插件实例、同配置路径的可信快照并告警；冷实例没有可信配置时暂停受影响操作。缓存不写盘，不由 CLI 跨进程借用。
- 补丁中断统一先回退再应用。新账本写 v2，新读取器兼容 v1/v2；旧代码拒绝 v2。降级前使用新版完成回退并确认账本清除。
- 非 UTF-8 源码整体拒写，不扩展编码支持。恢复与快照按字节处理。通用符号链接、ACL、硬链接改造及低影响 P3 留在后续范围。
- 本轮验收止于机制、隔离宿主与浏览器，不调用真实模型，也不据此宣称模型响应质量已经验证。
