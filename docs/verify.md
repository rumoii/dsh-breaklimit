## 固定宿主对账与预检

```powershell
$DshRoot = 'D:\host\deepseek-harness'
npm run reconcile -- "$DshRoot"
npm run check:host -- "$DshRoot"
```

对账应确认宿主 HEAD、插件版本声明与哈希来源一致。当前声明为 5 条补丁、10 个声明目标（推荐模式启用 4 条，`minimal.unfreeze` 只在完全解放里存在）；夹具导出 10 个文件，按全部声明预检产生 12 条结果、干净目标版本待写入 10 个文件（推荐档为 11 条结果、9 个文件）。另有 8 项宿主能力断言随预检一并执行。

`check:host` 从宿主 HEAD 导出临时夹具并清理，不写宿主工作树，也不检查其未提交修改。实际目标的预检用：

```powershell
node src/cli.js --host-root "$DshRoot" --status
```

## 沙箱与运行时

- 完全权限档：普通审批与升级审批的接管按设计执行。
- 只读档：写入被阻断，升级被拒绝；普通审批交还宿主。
- 工作区档：工作区外写入被阻断，不能借插件升级到完全权限。
- 提示词双点：装配前后点均存在；超限文件报错，不注入截断正文。
- 声明改写：匹配当前宿主措辞，未识别计数可见。

这些场景需要真实宿主触发源；缺少触发源时记为未验证，不用计数为零推断故障或通过。
